# 方向性: Cat Walk

## 仮説

Mac で作業する人 (と同じ人の iPhone / Apple Watch) に、作業の邪魔にならない常駐の癒しとして、画面の上を歩き回る 1 匹の猫を出す。macOS では透明でクリックを通す最前面のウィンドウの中を猫が歩き、iOS ではウィジェット・Live Activity・Dynamic Island で、watchOS ではコンプリケーションと watch アプリで、同じ猫が「動いて見える」。ログイン・サーバー・広告・育成要素を持たない (出典: 評価レポート https://github.com/bannzai/IdeaMemo/issues/366#issuecomment-6280604722 )。

## 判定基準

| 指標 | 計測元 (skill / コマンド) | 継続のしきい値 | 打ち切り条件 | 転換の条件 |
| --- | --- | --- | --- | --- |
| Mac App Store (jp + us) の直近 14 日の ★1〜2 レビュー数 | appstore-research skill: `bash ~/.agents/skills/appstore-research/scripts/fetch-reviews.sh <adamId> --country jp --pages 1` と `--country us` の出力で `date` が直近 14 日かつ `rating` が 2 以下の行数 | <= 1 | >= 3 x2 (2 回連続) | 低評価が「フルスクリーンで消える」「クリックを邪魔する」「CPU を食う」に集中していたら、新しい猫の動きより常駐の信頼性を改善 issue の最優先にする |
| Mac App Store (jp + us) の累積レビュー件数 (RSS で取れる本文付きレビュー) | 同上の出力の行数 (`--pages 2`) | 公開 28 日後に >= 5 | 公開 56 日後に 0 x2 | 公開 56 日後に iOS 側のレビューだけが付いていたら、iOS (Live Activity / ウィジェット) を主軸にする転換 |
| 買い切りの購入数 (課金を入れた場合) | App Store Connect の売上レポート | 公開 28 日後に >= 10 本 | 公開 56 日後に < 10 本 x2 | 購入 0 で表示回数が 3,530/月 を超えていたら価格・課金面の転換 (無料 + 季節の猫の買い切り等) |

平均評価は公開直後 0 件のため判定基準に入れない。10 件を超えたら agent が `>= 4.0` / `< 3.5 x2` の行を足す。Crashlytics・Analytics は入れない (`documents/adr/0001-local-only-no-backend-infra.md`) ため、クラッシュ・継続率の指標は置かない。adamId は App Store Connect でアプリを作った時に埋める。

## 必要な機能

2026-10-21 の構想の判断 (作る。 https://github.com/bannzai/IdeaMemo/issues/366#issuecomment-6300479645 ) で確定した一覧。進捗はロードマップの親 issue で管理する。

macOS:
- [x] メニューバー常駐 (`MenuBarExtra`、Dock に出ない) と、透明・クリック透過・最前面のオーバーレイ。全 Space・他アプリのフルスクリーン・複数ディスプレイの上に出る (#6)
- [x] 猫の歩行の状態機械 (歩く・立ち止まる・座る・眠る・毛づくろい)。画面下端を歩く。CPU はアイドル時 1% 未満を目標 (#4・#6。CPU は未計測)
- [x] 猫をドラッグで持ち上げて置ける (猫の上だけマウスを受け、それ以外はクリックを通す) (#7)
- [x] 設定: 猫の表示 / 非表示、サイズ、歩く速さ、ログイン時に起動。状態 (位置・設定) の保存 (#7)
iOS:
- [x] ホーム画面・ロック画面ウィジェット (猫の姿勢と位置をタイムラインで切り替え、タップで反応) (#8)
- [ ] ホーム画面 1 ページ分の特大ウィジェット (`systemExtraLargePortrait`、iOS 27 以降)。ページ全体を猫の部屋にし、タイムラインで猫の位置と姿勢が変わる (2026-10-26 に追加。起票元の「フルスクリーンウィジェット」の要望)
- [x] Live Activity / Dynamic Island で猫が歩く (最大 8 時間) (#10)
- [x] アプリ本体: 猫が歩く画面と撫でる操作 (#8)
watchOS:
- [x] コンプリケーション (accessory widget) と watch アプリ (前面では通常のアニメーション、Always On では静止) (#9)
共通:
- [ ] 歩行ロジックを共有する Swift Package (`CatWalkCore`) と、3 OS で同じ猫の見た目 (ロジックは #4 で共有済み。見た目は #12)
- [ ] 利用規約・プライバシーポリシー・紹介サイト (GitHub Pages) と、設定画面からの導線 (お問い合わせ (メール) の導線を含む) (サイトは公開済み。導線は #11)

MVP に入れないもの (後続): 育成・餌・ミニゲーム、複数の猫を同時に出す、自分の猫の柄の再現、季節のイベント、課金、動き・姿勢の種類の追加 (5 つの行動の先)。

## デザインの方向

- 2026-10-21 のモック (`documents/design/mock-2026-10-21/`、7 枚) に対する bannzai の返答 (2026-10-21、チャット): 「猫はもっと可愛く。あともっと種類を増やす」
- 猫の絵: モックの「輪郭線なし・2 色の丸い形・目 2 点」より、はっきり可愛さに寄せる (大きな目・丸い顔・短い手足。ドット絵ではなく柔らかいイラスト調)。質感 (ツヤのある 3D・金属・ネオン) と太い輪郭線のセルシェードは使わない (AI 生成の画像で見分けがつく定番の見た目を避けるため)。具体の絵は #12 で複数案を作り、PR で見てもらう
- 種類: 色・柄のバリエーション (茶トラ・三毛・黒・白・サバトラ・ハチワレ等) を複数用意し、設定で選べるようにする。同じ姿勢の絵を柄ごとに揃える。動き・姿勢の種類の追加は後続 (MVP に入れないもの)
- iOS / watchOS の表現 (更新の瞬間に姿勢と位置が変わる + 一言)、macOS の設定項目 (4 つ) はモックのまま (返答に異論なし)
