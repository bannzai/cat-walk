# 0001. バックエンド基盤を持たずローカルだけで完結させる

## Status
Accepted (2026-10-20)

## Context
Cat Walk は猫が画面上を歩くだけのアプリで、ユーザーのデータを扱わない。端末の外にデータが出ないことをプライバシーポリシーで明言できる。

MVP の段階でバックエンド基盤を持つと、運用・課金・プライバシーポリシーの記述が増える一方で、猫を歩かせるという価値の検証には寄与しない。

## Decision
MVP では DB・ストレージ・サーバー・認証・Analytics・クラッシュ収集・課金を持たない。設定は `UserDefaults` (`@AppStorage`) だけで保存する。

法務ドキュメントと紹介サイトは GitHub Pages (`docs/`) に置く。GCP / Firebase を使わないため、gcp-alert・crashlytics-alert・db-rules は対象外とする。

判定基準の計測は App Store のレビュー (appstore-research skill の `fetch-reviews.sh`) で行う。

## Consequences

**良い点:**
- 運用するサーバーやアカウントが無く、立ち上げと保守のコストが小さい
- 端末の外にデータが出ないため、プライバシーポリシーで明言できる

**悪い点 / 引き受けるリスク:**
- 利用者数・継続率は計測できず、ストアのダッシュボードとレビューに頼る。必要になった時に別 ADR で決め直す
